# rmacrostrat: Fetch Geologic Data from the 'Macrostrat' Platform

Work with the 'Macrostrat' (<https://macrostrat.org/>) Web Service (v.2,
<https://macrostrat.org/api/v2>) to fetch geological data relevant to
the spatial and temporal distribution of sedimentary, igneous, and
metamorphic rocks as well as data extracted from them.
